# Chinedu Sunday Okorie — Portfolio

Personal portfolio site. A single static `index.html` with no build step, served by GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Publish

The site is served at https://profchiso.github.io from the repo
`profchiso/profchiso.github.io`.

After pushing, go to **Settings → Pages → Build and deployment**, choose
**Deploy from a branch**, and pick `main` / `/ (root)`.
